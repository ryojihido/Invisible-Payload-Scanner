# Invisible Payload Scanner v0.1.0

Initial public release.

## Download

Download `InvisiblePayloadScanner-v0.1.0.zip`, extract it, and double-click:

```text
Start-InvisiblePayloadScanner.cmd
```

## Included

- Windows local Web UI
- GlassWorm-style variation selector run detection
- Visible decoder pattern detection
- Zero-width control character detection
- Trojan Source-style bidi control detection
- Hangul filler detection
- Progress display
- JSON export
- Local API token and Origin checks

## Notes

This is a first-pass screening tool, not a malware verdict engine. If it reports a finding, review the file type, surrounding code, execution path, and package origin.
